# Liszczanka Liszki – Official Club Website ⚽

A modern website for a local football club, designed and built with AI-assisted development tools.

## 🚀 Overview

This project is a fully functional website created for **Liszczanka Liszki football club**.
It focuses on providing essential information for fans, players, and the local community in a clean and accessible way.

The project demonstrates how AI can be used to **design, structure, and develop real-world web applications** efficiently.

## ✨ Features

* 📰 Club news and updates
* 📅 Match schedules and information
* 📊 Basic team and club data
* 🌐 Responsive web design
* ⚡ Fast and lightweight performance

## 🧩 Use Case

This project serves as:

* an official-style website for a sports club
* a template for small organizations or local communities
* a practical example of AI-assisted web development

## 🛠️ Tech Stack

* Frontend: AI-generated web interface (HTML, CSS, JavaScript)
* Backend: Supabase (PostgreSQL database, authentication, edge functions)
* AI Tools: Lovable (AI-powered development platform used for building and structuring the application)
* Development Approach: AI-assisted full-stack development
* Deployment: Vercel (serverless hosting and deployment)

## 📦 Installation

```bash id="a7h2kd"
git clone https://github.com/wookasha/liszki-club-dynamo.git
cd liszki-club-dynamo
npm install
npm run dev
```
